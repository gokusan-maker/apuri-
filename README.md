# えいたん

スマホで使える英単語学習アプリ（PWA）。相棒のモンスターを育てながら、ゲーム感覚で英単語を覚えます。
データは端末の中（localStorage）だけに保存され、サーバーはありません。オフラインでも動きます。
Claude Code の定期実行で自動開発しています。

- 開発計画: [ROADMAP.md](ROADMAP.md)
- 変更履歴: [CHANGELOG.md](CHANGELOG.md)

## できること

| 画面 | 内容 |
| --- | --- |
| 🃏 カード | 英→日（設定で日→英）のカード、発音・例文の読み上げ、スワイプで答える、間隔反復、1日の新出は10語まで、単語一覧・検索、★お気に入り |
| 🗺️ ステージ | 単語帳ごとに10語ずつのステージ（星1〜3）、全クリアで単語帳ごとのボス戦 |
| ❓ クイズ | 英→日／日→英／リスニング／例文リスニング／スペル／書き取り／穴埋め／並べ替え／不規則動詞／文法ミニ解説／発音練習（音声認識が使える端末のみ） |
| ⏱ タイム | 60秒タイムアタック、自己ベスト |
| 📊 記録 | ミッション、連続日数、今日の学習数、定着語数、週のグラフ、復習の予定、苦手・お気に入りの復習、マイ単語帳、バッジ、なかま、図鑑、画像でシェア、バックアップ |
| ⚙️ 設定 | 発音の速さ・米/英、テーマカラー、ダークモード、1日の目標、自動発音、文字の大きさ、効果音、ホーム画面に追加 |

相棒は正解でもらえる XP で育ち、Lv15 でよく使った学び方によって進化先が分かれます。
コインで着せ替えやおやつも買えます。

単語帳：中1・中2・中3（各100語）、高校基礎（100語）、熟語（80）、曜日・月（19）、テーマ別（75）、数（39）、色・形（19）、会話（20）。例文はすべてオリジナルです。

## 開発

```sh
npm ci
npm run dev      # 開発サーバー
npm run lint     # oxlint
npm test         # vitest
npm run build    # 型チェック＋ビルド（dist/）
```

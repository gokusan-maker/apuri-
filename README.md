# えいたん

スマホで使える英単語学習アプリ（PWA）。相棒のモンスターを育てながら、ゲーム感覚で英単語を覚えます。
データは端末の中（localStorage）だけに保存され、サーバーはありません。オフラインでも動きます。
Claude Code の定期実行で自動開発しています。

- 開発計画: [ROADMAP.md](ROADMAP.md)
- 変更履歴: [CHANGELOG.md](CHANGELOG.md)

相棒は正解でもらえる XP で育ち、Lv15 でよく使った学び方によって進化先が分かれます。
ショップの「タマゴガチャ」（🪙50）で新しいタマゴを引いて何匹も育てられます（仲間は12匹まで。さくら・うみ・よる＝レア、きんいろ＝スーパーレア、にじいろ＝ウルトラレアの色ちがいも）。Lv70 まで進化し（図鑑は全15種）、立体感のある絵で、まばたき・呼吸・キョロキョロと動き、さわると表情が変わります（夜は寝顔、おやつはもぐもぐ）。タマゴはかえる直前にひびが入り、進化は光の演出つき。部屋（全10種）は背景のイラストつき。学習した日数で「なつき度」が上がります。コインで着せ替え（頭・顔・首に1つずつ重ねられる）・部屋・おやつが買え、Lv10・20・30 では割引券ももらえます。1日の目標を達成すると相棒がおでかけして「おみやげ」を持ち帰ります。週末はXP2倍、季節のイベント・ラッキー単語・早起きボーナス・記念日などのごほうびもあります。

単語帳（全2730語）：中1・中2・中3（各100語以上）、高校基礎（460語）、熟語（210）、曜日・月（25）、テーマ別（414）、数（44）、色・形（24）、会話（120）。例文はすべてオリジナルです。

```sh
npm test         # vitest
npm run build    # 型チェック＋ビルド（dist/）
```

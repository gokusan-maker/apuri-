# えいたん

スマホで使える英単語学習アプリ（PWA）。相棒のモンスターを育てながら、ゲーム感覚で英単語を覚えます。
データは端末の中（localStorage）だけに保存され、サーバーはありません。オフラインでも動きます。
Claude Code の定期実行で自動開発しています。

- 開発計画: [ROADMAP.md](ROADMAP.md)
- 変更履歴: [CHANGELOG.md](CHANGELOG.md)

## できること

| 画面 | 内容 |
| --- | --- |
| 🃏 カード | 英→日（設定で日→英）のカード、発音・例文の読み上げ、スワイプで答える、間隔反復、1日の新出は5〜20語（設定で選べる）、単語一覧・検索、★お気に入り、メモ、不規則動詞の変化・まちがえやすい単語の解説 |
| 🗺️ ステージ | 単語帳ごとに10語ずつのステージ（星1〜3）、全クリアで単語帳ごとのボス戦、全ステージ星3でトロフィー |
| ❓ クイズ | 4択（英→日／日→英／英英／絵文字／英語→絵文字／例文の訳／ミックス／10秒／ライバル戦／しりとり／順番／ABC順／反対の意味／仲間はずれ／いくつある？／時計を読もう／色の名前／アルファベット／英語で計算／神経衰弱／単語ビンゴ／2人対戦）、聞く・話す（リスニング／聞き流し／聞き並べ／例文リスニング／書き取り／聞いて絵文字／数・時刻・日付・値段の聞き取り／発音練習）、書く・並べる（スペル／穴埋め／並べ替え／タイル）、文法・読解（文法ミニ解説22単元／まちがえやすい単語25組／読解25本／不規則動詞75語／発音のコツ7単元／複数形／過去形のつづり／比較級・最上級／3単現の s／ing形のつづり）。結果画面でまちがえた単語の一覧と★追加・シェア。日替わりの「今日のおすすめ」、かんたんモード（選択肢3つ） |
| ⏱ タイム | 30秒・60秒・90秒タイムアタック、自己ベスト |
| 📊 記録 | ミッション、週間チャレンジ、連続日数、カレンダー、週のグラフ、復習の予定、苦手・お気に入りの復習、マイ単語帳、バッジ、なかま、図鑑、画像でシェア、バックアップ |
| ⚙️ 設定 | 発音の速さ・米/英、テーマカラー、ダークモード、1日の目標・復習の上限、自動発音、文字の大きさ、効果音、テストの日、ホーム画面に追加、遊び方、新しくなったこと |

相棒は正解でもらえる XP で育ち、Lv15 でよく使った学び方によって進化先が分かれます。
コインで着せ替えやおやつも買えます。週末はXP2倍、ラッキー単語・早起きボーナス・記念日などのごほうびもあります。

単語帳（全1422語）：中1・中2・中3（各100語以上）、高校基礎（160語）、熟語（120）、曜日・月（25）、テーマ別（237）、数（44）、色・形（24）、会話（50）。例文はすべてオリジナルです。

## 開発

```sh
npm ci
npm run dev      # 開発サーバー
npm run lint     # oxlint
npm test         # vitest
npm run build    # 型チェック＋ビルド（dist/）
```

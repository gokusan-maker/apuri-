# えいたん

スマホで使える英単語学習アプリ（PWA）。相棒のモンスターを育てながら、ゲーム感覚で英単語を覚えます。
データは端末の中（localStorage）だけに保存され、サーバーはありません。オフラインでも動きます。
Claude Code の定期実行で自動開発しています。

- 開発計画: [ROADMAP.md](ROADMAP.md)
- 変更履歴: [CHANGELOG.md](CHANGELOG.md)

相棒は正解でもらえる XP で育ち、Lv15 でよく使った学び方によって進化先が分かれます。
キャラクターは6種類（モチ・コンコン〈キツネ〉・ペンペン〈ペンギン〉・ウサピョン〈ウサギ〉・ニャンタ〈ネコ〉・ドラコ〈ドラゴン〉）。勉強でためたコインでタマゴガチャを引いて集め、図鑑でコレクションできます。相棒は連続正解やまちがいのときにペットのように声をかけて励まし、小さいうちは日本語、育つと英語になります。「今日のチャレンジ」は相棒のキャラクターで問題の種類（単語・文法・並べかえ・リスニング・和文英訳・英文和訳）、育ち具合で難しさが変わります。ステージの「大学入試の塔」では、大学にちなんだ名前のボス9体と戦えます。ショップの「タマゴガチャ」（🪙50、7日連続で学習するともらえるチケットでも引ける）で新しいタマゴを引いて何匹も育てられます。相棒以外の子もおるすばんで少しずつ育ち、ホームの相棒カードからタップで交代できます（仲間は12匹まで。さくら・うみ・よる＝レア、きんいろ＝スーパーレア、にじいろ＝ウルトラレアの色ちがいも）。Lv70 まで進化し（図鑑は全15種）、立体感のある絵で、まばたき・呼吸・キョロキョロと動き、さわると表情が変わります（夜は寝顔、おやつはもぐもぐ）。タマゴはかえる直前にひびが入り、進化は光の演出つき。部屋（全10種）は背景のイラストつき。学習した日数で「なつき度」が上がります。コインで着せ替え（頭・顔・首に1つずつ重ねられる）・部屋・おやつが買え、Lv10・20・30 では割引券ももらえます。1日の目標を達成すると相棒がおでかけして「おみやげ」を持ち帰ります。週末はXP2倍、季節のイベント・ラッキー単語・早起きボーナス・記念日などのごほうびもあります。

単語帳（全3590語）：中1・中2・中3（各100語以上）、高校基礎（640語）、熟語（260）、曜日・月（25）、テーマ別（524）、数（44）、色・形（24）、会話（160）。例文はすべてオリジナルです。

## 開発

```sh
npm ci
npm run dev      # 開発サーバー
npm run lint     # oxlint
npm test         # vitest
npm run build    # 型チェック＋ビルド（dist/）
```

## 公開（Vercel で自動デプロイ）

`vercel.json` に設定済み。最初に1回だけ https://vercel.com/new で GitHub の `gokusan-maker/apuri-` を Import すると、以後はこのリポジトリに push するたびに自動でビルド・公開される（ビルド `npm run build`、出力 `dist`）。学習データは端末の localStorage が基本。設定の「クラウド保存・引き継ぎ」で Supabase に保存でき、引き継ぎコードで別の端末に復元できる（SQL は supabase/migrations/）。
